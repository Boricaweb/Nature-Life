
# NATURE-LIFE Web

My own web design for learning responsive website. The website content are about the photo of sky and wild that I had photograph. This challenge project is a part of Full-Stack Engineer course of www.codecademy.com


## Lessons Learned

**CSS components:** 
+ @media: for each device's layout
+ Responsive unit i.e. vw, vh, vmax, vmin, %, rem, em
+ @font-face: for managing web font

## Tech Stack

**Front-end:** HTML, CSS (responsive)
